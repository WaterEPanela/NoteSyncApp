# NoteSyncApp

Note Sync App is a simple Android application that allows users to create and manage notes directly on their device, with support for syncing `.md` (Markdown) files across devices on demand.

> **Status**: Work in Progress (WIP)

## Features (Planned)
- Create, edit, and delete notes.
- Save notes as Markdown (.MD) files.
- Sync notes across devices (manual or local network).
- Clean and intuitive UI.
- privacy first (no clouds, no external services)

## Tech Stack
- Kotlin (primary language)
- Android SDK
- Room Database (planned)

## Setup
1. Clone the repo: `git clone https://github.com/your-username/NoteSyncApp.git`
2. Open in Android Studio
3. Build and run on an emulator or device
